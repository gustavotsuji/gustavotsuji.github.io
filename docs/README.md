## 🏗️ Stack Tecnológica

- **Framework**: Next.js 16.1.1 (App Router, Turbopack)
- **UI**: React 19.2.3
- **Linguagem**: TypeScript 5.3.3
- **Estilo**: Tailwind CSS 4.1.18 (CSS-first)
- **Runtime**: Node.js 24.x
- **Gerenciador de Pacotes**: Yarn 1.22.22
- **Testes**: Jest 30.2.0 + React Testing Library 16.3.1
- **Qualidade**: ESLint 9.39.2 + Prettier 3.7.4 + Husky 9.1.7
